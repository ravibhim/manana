# Commit

Create a git commit for the current changes.

## Instructions

1. Run `git status` and `git diff` to understand the changes
2. Stage the relevant files (prefer specific files over `git add -A`)
3. Write a brief, descriptive commit message (1-2 lines max)
4. Do NOT include a Co-Authored-By line
5. Commit the changes
